# C++ Networking & Security Research

A collection of C++ projects exploring network programming, internet protocols, and security research. Projects focus on understanding and implementing RFC-defined behavior, building defensive diagnostics, and testing systems in environments you own or are explicitly authorized to assess.

## Focus areas

- **Networking:** sockets, client/server applications, packet handling, and protocol tooling
- **RFCs:** educational implementations and tests based on published protocol specifications
- **Security research:** defensive analysis, safe validation, and authorized lab exercises
